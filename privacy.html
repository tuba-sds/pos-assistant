Privacy Policy — POS Assistant

Last updated: 4 October 2026

Who this covers

POS Assistant has exactly one user: its author, who is also the owner of the Google accounts it reads. There are no other users and no sign-up. This policy describes how the author's own data is handled by the author's own software.

What is accessed

  • gmail.readonly — reading the owner's mail to decide what needs attention.
  • gmail.compose — creating draft replies in the owner's account. This scope cannot send mail.
  • calendar.readonly — reading the owner's calendar to find conflicts.

Where data goes

Message content is stored only on the owner's personal computer. It is not uploaded to any server, database or analytics service, and is not shared with any third party.

To classify what is urgent, a reduced record containing only sender, recipients, subject, date and labels is sent to the language-model API that performs the sorting. Message bodies are never sent. This restriction is enforced in code by an allowlist, and the program aborts if a message body ever reaches that path.

Summaries are delivered to a private Discord server owned by the author, with no other members.

What is never done

No email is ever sent, forwarded, trashed or deleted. No calendar event is created, modified or deleted. No data is sold, shared, or used for advertising, profiling or model training.

Retention and deletion

Data lives in local files on the owner's computer and is deleted by deleting those files. Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends all access.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
